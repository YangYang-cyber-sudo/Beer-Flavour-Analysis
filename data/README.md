# Data directory

**No measurement data are stored in this repository.**

The five input files are downloaded from the public Zenodo deposit of
Schreurs et al. (2024), DOI [10.5281/zenodo.10653704](https://doi.org/10.5281/zenodo.10653704),
and placed in `data/raw/`:

```text
data/raw/
├── 1.csv                              # 250 x 231 chemical properties
├── 4.csv                              # 250 x 50 trained-panel descriptors
├── 6.csv                              # 44 x 50 chemical-sensory correlations
├── 8.xlsx                             # thresholds + calibrated chemistry
└── Raw sensory data anonymized.csv    # 2,197 raw session records
```

`data/raw/` is git-ignored. SHA-256 checksums, shapes and the role of each
file are in [`../docs/DATASET.md`](../docs/DATASET.md). Do not edit these files;
the loader enforces the documented shapes and refuses to drop or impute rows.

Set `BEER_DATA_DIR` to use a directory elsewhere:

```powershell
$env:BEER_DATA_DIR = "D:\beer-data"
```

```bash
export BEER_DATA_DIR=/data/beer
```

## `data/derived/`

`data/derived/` contains **archived upstream inputs**, not new results. They
are outputs of the earlier Q1/Q2 analysis that the included reanalysis scripts
read, kept so the reanalysis can run without refitting those upstream models.
Their exact provenance is documented in
[`derived/README.md`](derived/README.md) and in
[`../docs/DATA_DICTIONARY.md`](../docs/DATA_DICTIONARY.md).

Nothing under `data/derived/` is a measurement table; all of it is derived from
the public deposit and can in principle be regenerated by the upstream Q1/Q2
pipeline, which is outside the scope of this repository.
